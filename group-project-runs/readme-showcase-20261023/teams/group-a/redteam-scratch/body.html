Call Review Lab

Call Review Lab turns speaker labeled call transcripts into an account timeline and a coaching report. Calls without recordings stay in the timeline so gaps remain visible. It is for people coaching on sales or customer calls, with the account owner reviewing the result.

python3 run.py demo

The demo imports a synthetic call and writes workspace/report.html. This capture of that report shows measured talk share and question marks, with each quote checked against a single speaker turn (Harbor Tools is demo data):

Requirements

Python 3.10 or newer, per the repo's own README. The Python commands use only the standard library.

With your own calls

python3 run.py init
python3 run.py import-csv /path/to/calls.csv
python3 run.py review
python3 run.py report

Convert each transcript to Markdown turns first. The measures count words and question marks, not speaking time or question quality. A call with no transcript appears as Transcript absent. For the qualitative analysis, the repo supplies a prompt, prompts/analyze_call.md; it does not run a model for you. The method is in docs/METHOD.md.

Limits

  • The demo output shown here is the committed report, not a fresh run.
  • Human review is required for coaching conclusions.
