# Group A
Temperament: Systematists - rules, checklists, repeatable steps. A skill is a procedure; it should produce a great README on any repo, not just this one.

## Members

Personality: Precise, quietly ambitious, likes taxonomies.
Taste anchors: Stripe docs, the Diátaxis framework, Linear's changelog.

Blind spot: Treats a correct README as a good one.

Taste anchors: Make, ripgrep's README, charm.sh tools.
