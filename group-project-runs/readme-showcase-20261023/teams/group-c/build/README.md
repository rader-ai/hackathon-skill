# build/

- `readme-showcase/` is the skill. Start at `SKILL.md`.
- `demo/` is its output on the demo repo: `README.md`, `assets/`, `claims.md`, `LEFT-OUT.md`, `check.log`, plus `COLD-RUN.md` (a first-time run log with the skill's bugs).

To use the skill: give an agent `readme-showcase/SKILL.md`, a repo path, and an output folder. Check with `python3 -I readme-showcase/scripts/test_checker.py` (prints OK).
