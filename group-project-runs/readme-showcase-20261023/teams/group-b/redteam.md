## Ranked issues (most expensive first)

2. **Hero Reel misleads and has a raw-markdown flaw** (skill + demo). First thing on screen is `**Jordan** [00:40] ...` with literal asterisks, then a CHECK card reading `"checked": 4,`, then an OUTPUT card reading just `Quote verified`. A newcomer cannot tell what "checked: 4" means, and the step implies that one transcript line produced the count of 4 (it is the count across four quote slots, two of which are the same quote). Tomas will trace INPUT -> `4` -> badge and call it a causal story the files do not tell. Alt text is the same junk: `Input: **Jordan** [00:40] ... "checked": 4,` with an HTML-escaped `&quot;`. Fix (skill): beats.md must say strip markdown emphasis from beat text and pick the CHECK line a human can read (the `verification.json` entry `"ok": true` plus its `quote`, or "4 quotes checked, 0 failed" as a derived claim row). Fix (demo): INPUT = the transcript line without asterisks, CHECK = `"ok": true` for that exact quote, OUTPUT = the visible quote with its Quote verified badge. Write the alt as a sentence, not a transcript of the SVG.

3. **The one-sentence "what it is" sits below a ~380 px animated card** (demo). At 1012x900 I see title, the Reel, then the sentence at y=535 and the install block at y=630. 4. **"Unverified" disclaimers are a tax the maintainer would delete** (skill + demo).
