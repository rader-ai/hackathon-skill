### Jess Alvarez - Audience Proxy (developer browsing GitHub)

Full-time backend developer who skims GitHub between tickets and decides in seconds whether a repo earns a star or a clone. Has tried a lot of tools that looked great on the landing page and died on the first `install` step.

Loves: a first screen that says what the thing does, who it is for, and the exact command to try it, with real output or a real screenshot instead of stock art.
