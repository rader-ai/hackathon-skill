The goal should be a skill that any developer can point at an unfamiliar repo and get back a README they'd be proud to ship as the project's front door: a stranger understands what the project is for and why it matters within moments, and can actually get it working. Everything on the page should be true to the repo - real output, accurate setup, no invented claims - so the README earns trust rather than spending it. And the result should hold up on repos the authors never saw, not just the demo.
