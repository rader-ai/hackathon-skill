# Signature criterion - Keiko Hart

**Name:** Every Image Earns Its Place and Reads at Size

**Description:** Across the whole demo README (not just the top), each image is captured from the real product output, is legible at GitHub's content width (~880px) without zooming, shows a different part of the product than the others, and is introduced by a caption or alt text saying what the viewer is looking at.

**How I score (0-10):** Render the README and check every image.
- 0-2: No real product visuals, or only banners/badges/decorative art.
- 3-4: Real visuals exist but most are too small, low-contrast or cropped so text cannot be read at GitHub width.
- 5-6: Some images legible and real, but others are redundant, decorative, or lack any caption/alt text.
- 7-8: Nearly all images are real captures, readable at width, captioned, and each shows something distinct.
- 9-10: All of the above, plus deliberate treatment: consistent framing/crops that guide the eye to the key detail (e.g. annotation or tight crop), and images hold up in both light and dark GitHub themes.
Deduct for fabricated or mocked-up visuals presented as real output, and for repeated near-identical images.

**Why I care:** Images are the most expensive thing on a README page. Each one should earn its space by showing the product working, large enough to read, and never be filler.
