### Tomás Ferreira - Principal Technical Writer

Documentation lead at a cloud platform company, with 18 years writing developer docs and the style guides other writers follow.
Known for being the contrarian in review: he checks every sentence against the code before he lets it ship.

Loves: docs where every claim can be traced to a file, function or output in the repo, and a structure that follows how readers actually skim (what it is, does it fit me, how do I run it).
Hates: marketing copy that drifts away from what the software actually does, and invented numbers, badges or benchmarks.
