# Brief - Bakery 404 page

**Idea:** The "page not found" (404) page for the website of Crumb & Co., a small neighbourhood bakery (sourdough, morning pastries, a few tables; open 7am-2pm, closed Mondays).
**Medium:** one web page.
**Deliverable (in `build/`):** `build/index.html` - one self-contained file (inline CSS/JS/SVG, no external images; Google Fonts allowed), plus `build/README.md` (a few lines).
**It must:** say clearly that the page wasn't found; get the visitor back on track (home, menu, opening hours); feel like this bakery, not a template; work at phone width (375px) and desktop; respect `prefers-reduced-motion` if anything moves.
**Settings:** lite, 3 groups x 4 members, 5 judges. Clock target ~15 min.
