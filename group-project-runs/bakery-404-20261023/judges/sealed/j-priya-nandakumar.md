# Sealed - j-priya-nandakumar
**Name:** Survives without the extras
**Description:** Does the page still work - message readable, links usable - with JavaScript disabled and before web fonts load? And is the file lean (no bloated inline assets)?
**Scoring 0-10:** 0 = blank or broken without JS/fonts; 5 = usable but layout shifts or key content missing; 10 = fully functional with JS off, no jarring font swap, file comfortably small.
**Why she cares:** Her clients' visitors arrive on patchy mobile signal; a 404 is the last page that should fail.
