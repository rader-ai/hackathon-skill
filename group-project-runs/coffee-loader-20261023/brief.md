# Brief - Coffee App Loading Indicator

**Idea:** A 5-second animated loading indicator for a coffee app (an app for ordering coffee from local cafés).
**Medium:** UI motion graphic, built in plain HTML/CSS.
**Constraints:**
- One self-contained `build/index.html` that opens directly in a browser, no build step, no external JS. CSS animation only (a few lines of JS allowed only to restart/replay). Inline SVG is fine. No external images.
- One full cycle runs 5 seconds and must loop seamlessly (it may be shown for longer than 5s while an order loads).
- Must look good at 120×120px (in-app) and scale up to a full splash.
- Must respect `prefers-reduced-motion`.
- The app's brand is open - teams may propose a palette.

**Settings:** mode lite, 3 teams × 4 members, 5 judges.
